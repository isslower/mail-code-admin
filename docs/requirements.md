# 邮箱接码后台需求整理

## 1. 项目定位

做一个网页版邮箱管理后台，类似 Foxmail 的网页管理版本，用来统一管理多个邮箱账号，集中接收验证码邮件，并支持普通邮件收发和删除。

当前阶段先做个人或内网使用版本，重点是能跑通核心流程：登录后台、添加邮箱、同步收件、查看验证码、发送邮件、删除邮件。

## 2. 目标用户

- 管理员：维护邮箱账号、查看所有邮件、发送邮件、删除邮件。
- 操作员：快速查看验证码、复制验证码、筛选邮箱和邮件。

## 3. 核心功能

### 3.1 登录界面

- 管理员账号密码登录。
- 登录后进入后台管理页面。
- 未登录不能访问接口数据。

### 3.2 邮箱账号管理

- 添加多个邮箱账号。
- 每个邮箱配置：
  - 显示名称
  - 邮箱地址
  - IMAP 服务器、端口、SSL
  - SMTP 服务器、端口、SSL
  - 登录账号
  - 授权码或密码
- 查看已添加邮箱。
- 手动同步指定邮箱。
- 删除邮箱账号和本地邮件记录。

### 3.3 收件箱

- 聚合显示所有邮箱收到的邮件。
- 支持按邮箱筛选。
- 支持按发件人、主题、正文、验证码搜索。
- 邮件列表显示：
  - 所属邮箱
  - 发件人
  - 主题
  - 正文预览
  - 收件时间
  - 识别到的验证码
- 点击邮件查看详情。

### 3.4 验证码识别

- 自动从主题和正文里提取 4-8 位数字验证码。
- 单独提供“验证码”视图，只展示识别到验证码的邮件。
- 邮件详情页可以一键复制验证码。

### 3.5 发送邮件

- 选择一个已配置邮箱作为发件邮箱。
- 填写收件人、主题、正文。
- 通过 SMTP 发送邮件。

### 3.6 删除邮件

- 本地删除：只隐藏本系统里的邮件记录，不删除邮箱服务器上的邮件。
- 服务器删除：通过 IMAP 删除邮箱服务器上的邮件。
- 服务器删除属于危险操作，需要二次确认。

## 4. 页面结构

- 登录页
- 后台主界面
  - 收件箱
  - 验证码
  - 发送邮件
  - 邮箱账号

## 5. Demo 界面内容

Demo 阶段不连接真实邮箱，只展示产品形态：

- 左侧导航。
- 顶部统计和筛选。
- 示例邮箱账号。
- 示例验证码邮件。
- 示例邮件详情。
- 示例发送邮件面板。
- 示例账号管理面板。

## 6. 后续可扩展功能

- 批量导入邮箱账号。
- 自动定时同步邮件。
- 多管理员和权限管理。
- 邮箱授权码加密存储。
- 邮件附件查看和下载。
- 邮件已读/未读状态。
- 操作日志。
- 验证码接口 API，供其他系统自动读取。
- Docker 部署。
- 公网部署时增加 HTTPS、风控和访问限制。

## 7. 安全注意事项

- 邮箱授权码属于敏感信息，正式上线前需要加密保存。
- 服务器删除邮件不可恢复，需要保留确认机制。
- 公网使用必须启用 HTTPS。
- 管理员密码不能使用默认密码。
- 建议增加登录失败限制和操作日志。
